# AI Rules

## Mission

Build Upa OS by following the documentation before writing code.

## Mandatory Rules

-   Read relevant docs before implementing.
-   Never invent business rules.
-   Follow architecture decisions.
-   Reuse existing services.
-   Keep changes small and focused.
-   Do not introduce new dependencies without an ADR.
-   Ask for clarification if documentation is ambiguous.

## Coding Priorities

1.  Correctness
2.  Maintainability
3.  Simplicity
4.  Performance
