# 27 Development Roadmap

## Guiding Principles

-   Deliver working software at the end of every phase.
-   Keep features small and testable.
-   Deploy early and iterate.

## Phase 1 -- Foundation

-   Initialise Next.js project
-   Configure Supabase
-   Authentication
-   Design system
-   Layout shell

## Phase 2 -- Core Data

-   Database schema
-   Tenant management
-   Billing cycles
-   Settings

## Phase 3 -- Billing Engine

-   Meter readings
-   Electricity calculations
-   Snapshot generation
-   Validation

## Phase 4 -- SOAs

-   PDF generation
-   Preview
-   Download
-   Historical regeneration

## Phase 5 -- Payments

-   Payment recording
-   Outstanding balances
-   Payment history

## Phase 6 -- Automation

-   Reminder emails
-   Vercel Cron
-   Dashboard notifications

## Phase 7 -- Polish

-   QA
-   Performance
-   Accessibility
-   Production deployment
