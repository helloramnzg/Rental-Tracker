# 26 Settings Screen

## Purpose

Configure application settings that change infrequently.

## Sections

### Property

-   Property Name
-   Address

### Tenants

For each tenant:

-   Name
-   Email
-   Mobile
-   Monthly Rent

### Utility Settings

-   Electricity Rate (₱15/kWh default)
-   Default Water Charge

### Reminder Schedule

-   Reminder 1 Day
-   Reminder 2 Day
-   Reminder 3 Day

### Payment Details

-   Bank Name
-   Account Name
-   Account Number
-   GCash Number

## Validation

All required fields must be completed before saving.

## Actions

-   Save Changes
-   Reset Unsaved Changes

## Future Expansion

Support:

-   Multiple properties
-   Multiple landlords
-   Notification preferences
-   Branding
