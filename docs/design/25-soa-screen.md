# 25 SOA Screen

## Purpose

Review, preview and download monthly Statements of Account.

## Layout

-   Header
-   Billing Month Selector
-   SOA Cards
-   PDF Preview
-   Action Bar

## SOA Card

Display

-   Tenant
-   Unit
-   Status
-   Generated Time

## Actions

-   Preview PDF
-   Download PDF
-   Regenerate PDF

## Preview

The preview should closely match the generated PDF.

## Download

Support:

-   Individual SOA
-   Download All

## Regeneration

Always regenerate using billing snapshots, never current tenant data.

## Empty State

"No Statements of Account have been generated."

Primary Button:

Generate SOAs
