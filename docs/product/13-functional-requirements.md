# Functional Requirements

## Purpose

Defines every feature the application must provide.

## Core Modules

-   Authentication
-   Dashboard
-   Tenant Management
-   Monthly Billing
-   Electricity Calculator
-   SOA Generation
-   Payment Tracking
-   Reports
-   Settings

## Dashboard

-   Show current billing cycle
-   Show monthly checklist
-   Show payment status
-   Show reminder status

## Billing

-   Create one billing cycle per month
-   Store mother meter bill
-   Store current submeter reading
-   Calculate electricity automatically
-   Lock closed billing cycles

## SOA

-   Preview
-   PDF generation
-   Regenerate from billing snapshot
-   Manual download

## Payments

-   Record full or partial payments
-   Update balances
-   View payment history

## Notifications

-   25th reminder
-   26th reminder
-   27th SOA notification

## Non-functional

-   Responsive
-   Secure
-   Fast
-   Audit-friendly
