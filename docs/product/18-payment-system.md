# Payment System

## Payment Status

-   Outstanding
-   Partial
-   Paid

## Record

-   Date
-   Amount
-   Method
-   Reference Number
-   Notes

## Rules

-   Multiple payments allowed.
-   Remaining balance rolls into the next billing cycle.
-   Payment history cannot be deleted after billing is closed.
